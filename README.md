School Management System - Frontend

This is the frontend of a School Management System built with React, Redux, and Tailwind CSS. It provides a user-friendly interface for admins, staff, and students to manage school-related tasks.

🛠 Tech Stack
Frontend: React, Redux Toolkit, React Router
State Management: Redux Toolkit
Styling: Tailwind CSS
Notifications: sonner (for toast messages)
API Calls: Axios

🚀 Features
Authentication (Admin, Staff, Student)
Dashboard with Analytics
Manage Students & Teachers (CRUD operations)
Classroom & Subject Management
Attendance Tracking
Live Chat with WebSockets
Secure API Integration

📦 Installation
1️⃣ Clone the Repository
git clone https://github.com/ayshashfi/School-FRONTEND.git
cd School-FRONTEND

2️⃣ Install Dependencies
npm install

3️⃣ Run the Development Server
npm start

🚀 Deployment
To build for production:
npm run build
